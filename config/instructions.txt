Forgejo MCP server for managing Forgejo/Gitea instances. Supports multiple instances and users.

Every tool except list_forgejo_instances and get_forgejo_mcp_server_version requires 'instance' (Forgejo instance name) and 'user' (configured user identity); list_forgejo_instances shows the valid values. 'owner'/'repo' identify a repository; 'index' is the issue/PR number.

Covers repositories, issues, pull requests and reviews, files, branches, tags, releases, packages, organizations and teams, notifications, time tracking, push mirrors, and Actions (runs, jobs, logs, secrets).

Tips:
- Action log download via REST requires Forgejo 16+; get_forgejo_version reports what an instance supports.
- Resources (forgejo:// URIs) provide read-only access to specific entities by URI.
- A merge_pull_request timeout is NOT a failure: the tool reports 'merged' or 'in_progress'. Never retry a merge after a timeout; check get_pull_request_by_index instead.

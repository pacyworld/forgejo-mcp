Forgejo MCP server for managing Forgejo/Gitea instances. Supports multiple instances and users.

Use list_forgejo_instances to see configured instances. The 'instance' and 'user' parameters are required on all tool calls.

Key capabilities:
- Repository management (create, fork, search, list)
- Issue tracking (create, update, close, comment, labels, milestones)
- Pull requests (create, review, merge, diff)
- File operations (read, create, update, delete)
- Branch management (create, delete, list)
- Release management (create, edit, delete, attachments)
- Notifications (check, mark read)
- Workflow/Actions (dispatch, list runs/jobs, download job/run logs — log download via REST API requires Forgejo 16+; tools detect the server version and degrade gracefully)
- Time tracking (add time, stopwatch, tracked times)
- Organization teams (search)

Tips:
- Pass instance and user explicitly to every tool call
- Resources (forgejo:// URIs) provide read-only access to specific entities by URI
- Merges on large repositories can exceed the request timeout. merge_pull_request verifies the PR state on timeout and reports 'merged' or 'in_progress' — a timeout is NOT a failure. Never retry a merge after a timeout; check get_pull_request_by_index instead.
